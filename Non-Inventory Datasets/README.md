This folder includes the following files:
1. Climate Data.csv -> environmental data for the 32 study cities
2. Downtown Areas.csv -> a list of the Dissemination Areas (DAUIDs) that are in the Statistics Canada's delineated downtown areas.
3. Families.csv -> used to join the family based on the genus
4. Location Index.csv -> a list that links City to province, ecozone, population (continuous), city size (ordinal), and downtown core (Y/N)
5. Reviewed Nomenclature.csv -> a file indicating what corrected names have been reviewed in POWO.
6. Species Corrections.csv -> used to correct errors in botanical names
